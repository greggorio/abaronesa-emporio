# Harmonização

Harmonização é o sub-domínio que governa os vínculos entre produtos que combinam entre si. Existe para sugerir combinações ao cliente (ex: vinho + comida) com tipo, descrição e ordem de exibição.

Pertenço a [`produtos/`](../README.md).

## Domínio

- [`harmonizacao.md`](./harmonizacao.md) — modelo de dados (ProdutoHarmonizacao), regras (auto-harmonização, duplicidade), endpoints e decisões

## Leitura contextual

Harmonizações são relacionamentos N:M entre produtos, com SKU opcional para vínculo específico. O cadastro é manual — não há sugestão automática.
