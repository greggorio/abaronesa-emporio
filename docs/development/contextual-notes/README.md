# Notas Contextuais

Esta subarea agrupa documentos tecnicos que continuam uteis para desenvolvimento ativo, mas nao devem ser lidos como referencia geral da plataforma.

## Conteudo Atual

| Documento | Papel | Status |
|-----------|-------|--------|
| [CONTINUATION_GUIDE.md](./CONTINUATION_GUIDE.md) | Nota de continuidade de implementacao especifica | `contextual` |
| [ROOT_LAYOUT.md](./ROOT_LAYOUT.md) | Nota tecnica sobre organizacao da raiz do repositorio | `contextual` |

## Quando Um Documento Deve Ficar Aqui

- quando estiver fortemente ligado a uma tarefa, iteracao ou implementacao especifica
- quando ainda for util para o trabalho ativo
- quando nao fizer sentido apresenta-lo como guia recorrente para todo desenvolvedor

## Quando Um Documento Deve Sair Daqui

- quando virar referencia recorrente e reutilizavel
- quando ficar obsoleto e puder ser arquivado
- quando passar a descrever comportamento funcional, integracao ou API e portanto pertencer a outra secao
