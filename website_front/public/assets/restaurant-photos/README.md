# Fotos do Restaurante

## Como adicionar as fotos

Para o sistema Point-and-Click funcionar com as fotos reais, salve as 3 fotos neste diretório com os seguintes nomes:

### 📸 Fotos necessárias:

1. **photo1.jpg** - Área de jantar com mesas e pelegos (primeira foto que você enviou)
2. **photo2.jpg** - Visão geral do salão (segunda foto)
3. **photo3.jpg** - Bar com chopeiras e logo Dalla (terceira foto)

### 📁 Estrutura esperada:
```
public/assets/restaurant-photos/
├── photo1.jpg (Área de Jantar)
├── photo2.jpg (Visão Geral)
└── photo3.jpg (Bar Dalla)
```

### 💡 Dica:
- Use fotos em alta resolução para melhor qualidade
- Formato recomendado: JPG ou PNG
- Tamanho recomendado: 1920x1080 ou superior

### 🔄 Depois de adicionar as fotos:
O sistema detectará automaticamente e carregará as imagens. Se uma foto não for encontrada, aparecerá um placeholder indicando qual arquivo está faltando.
