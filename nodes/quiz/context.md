# Quiz — Contexto

## Comunicação em tempo real

O módulo depende de WebSocket para o loop de quiz ao vivo: perguntas são disparadas, respostas são coletadas e o ranking é atualizado sem recarregamento de página.

## Integrações conhecidas

- **Clientes**: participantes são identificados (vinculados ao sistema de clientes do estabelecimento)
- **Dashboard**: expõe métricas de engajamento do quiz (taxa de resposta, acertos, participação por sessão)

## Gamificação

A pontuação e o ranking ao vivo funcionam como mecanismo de gamificação para aumentar o engajamento durante eventos e noites presenciais.

## Status

O módulo está em desenvolvimento. Não há definição pública de API REST ou contratos de evento além do WebSocket.
