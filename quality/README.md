# Quality

Esta area concentra os ativos de qualidade do projeto como um todo.

O sistema deve ser tratado como um unico produto com ambientes e superficies
distintas, e nao como dois projetos desconectados. Por isso, os ativos de
qualidade ficam fora dos modulos individuais quando o escopo for transversal.

## Estado atual

- Existe apenas material pontual de validacao automatizada.
- A estrutura definitiva de testes do projeto ainda nao foi formalmente definida.
- A pasta atual deve ser lida como transitoria.

## Observacao

A definicao detalhada de escopo, nomenclatura e estrutura interna de testes deve
ser tratada como item de roadmap do projeto unificado ERP + site.
